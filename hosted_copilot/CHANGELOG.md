# Hosted Toolkit Changelog

All notable changes to the Hosted Toolkit will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/). The Hosted Toolkit is deployed directly from this source repository, so its history remains unversioned unless its distribution model changes.

## [Unreleased]

### Added

- Introduced the source-deployed Hosted review experiment with compact path-specific guidance for documentation, Go implementation, and acceptance tests, plus controlled paired-review workflows for comparing Hosted and control results.
- Added a normalized Hosted rule catalog and read-only intake workflow that evaluates upstream contributor guidance, Interactive rules, and Maintainer Proposals with reusable semantic assessments, guidance-capacity reporting, portable drafts, and auditable promotion contracts.
- Added versioned source definitions, parser contracts, deterministic collection-only inventories, complete-corpus assessment and reconciliation, and one disposable Workbench display with canonical source and catalog binding.
- Added the Hosted Rule Workbench as a laptop-and-desktop Hosted-rules IDE with searchable candidate and assessment views, persistent decisions, promotion-plan review, guarded capacity projections, source-backed diffs, exact approved-rules export, and repository-read-only loopback serving.
- Added an explicit bounded relationship check for edited wording and planned catalog mutations against the complete projected active and protected catalog. Unchanged, off-Plan proposals retain original issue evidence without new validation tasks or inferred mutations. Add still requires checking when wording equals the generated baseline. Details and Promotion Plan share one current result: clean checks satisfy the relationship gate, wording or Plan changes require revalidation, and failures retain saved wording. Review Changes counts issues affecting the projected catalog without hiding unrelated baseline evidence or waiving protected/integrity blockers; off-Plan previews cannot clear original publication issues. Transient failures offer Retry beside Close; fix-first failures require correction before another request. Requests use the configured `ruleEvaluation` profile with a five-minute transport deadline and owned cancellation. Export verifies server-held results against current proposals; imported drafts and stale receipts cannot carry trusted approval evidence. Checking does not restore automatic scope review, rescoring, or grouped saved-edit adjudication.
- Added AI Assistance in one resizable sidebar with a permanent titlebar toggle and sidebar close button. Candidate and Assessment views retain independent in-memory conversations for each rule, including input, reading position, and pending requests. Navigation and hiding never cancel work; replies, cancellation, and busy borders affect only their owning chat. The header plus and X match the titlebar's button sizing and spacing. New Chat opens one shared confirmation with view-specific AI chat wording, a warning title icon, and a trash-marked red Clear Chat action. Only confirmation removes the originating conversation's Workbench history and excludes it from future requests; Cancel, X, and Escape preserve it. Other chats, unsent input, rule edits, and catalog context remain intact; v1 does not archive old chats or offer undo. The composer provides the single Send/Stop control. Advice uses the normal model, recorded assessment and source-contribution evidence, scoring definitions, and the complete active and protected catalog snapshot. It can explain original ratings and challenge missing source meaning while distinguishing recorded evidence from edited wording and new advisory analysis; other drafts and projected Plan changes remain unchecked. Copy-only suggestions never edit or approve rules. Replies retain measured completion time, safe catalog-context notes, inline wording, and copy actions. Failures use one compact inline error with a secondary Diagnostic Reference and right-aligned retry, including generic fallbacks and repeated failed retries; the retired titled error card cannot return. Submitted input clears immediately and is restored on failure or cancellation without overwriting newer drafts. Conversations reset on reload, oversized context fails without truncation, and diagnostics exclude raw conversations, CLI output, and credentials.
- Added an icon-first Promotion Plan filter that isolates items needing maintainer attention, reports the outstanding count, and follows existing header active, hover, tooltip, and disabled-state behavior.
- Added responsive Rule Issue type paging that keeps labels and counts intact, reacts to panel resizing, hides navigation when all tabs fit, and keeps the selected category visible when space shrinks. The final page includes preceding tabs that still fit, while manual Previous and Next navigation retains clear edge states.
- Added shared transparent waiting panels with accessible title and body text, a muted-gray character chase and three-character white highlight, a smooth 3.5-second multicolor chase on all four pixel-aligned border edges, and reduced-motion support. Relationship checks show elapsed time and a native Stop icon; timer updates preserve the mounted panel, focused cancellation control, and animation. Navigation remains responsive, operation-owned cancellation rejects late results, and authenticated shutdown stops the owned workers without losing saved wording.
- Expanded the pinned, locally hosted Codicon inventory with folder-state, directory-link, workspace-trust, remote-connection, reconciliation-conflict, the complete 14-icon Copilot family, and all 21 layout-family icons for current and future Workbench surfaces. Offline sprite and preview generation preserve native geometry, including compact, standard, and large Copilot variants and both right-sidebar visibility states.
- Added a dedicated, attributed LLM icon family retaining all 340 standard AI-brand glyphs from a pinned Lobe Icons catalog, without color or wordmark variants. Its runtime manifest selects four brand icons; a separate chat presentation map selects GPT/OpenAI, Claude, Gemini, and Grok branding from the effective configured model. The PNG inventory still previews the complete family. Unmapped models retain their actual name and effort with the existing Codicons question-mark fallback, without changing CLI availability or the fixed Copilot identity.
- Added a shared native-PowerShell help renderer across all four normal maintainer commands with side-effect-free `-Help`, `-h`, and `-Detailed` menus, complete native `-?` and `Get-Help` topics, semantic terminal styling, and parameter-set enforcement that keeps help independent from operational requirements.
