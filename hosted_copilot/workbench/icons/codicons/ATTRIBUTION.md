# Visual Studio Code Codicons

The SVG files in this directory are selected icons from
[Microsoft's Visual Studio Code Codicons](https://github.com/microsoft/vscode-codicons)
at commit `1c47ab36a4bb845c437866405c2fa67b8ca0fe36`.

Copyright Microsoft Corporation. Licensed under the
[Creative Commons Attribution 4.0 International license](LICENSE.txt).

`sprite.svg` combines the selected icon geometry into SVG symbols for local Hosted Rule Workbench use. It is generated by `hosted_copilot/tools/New-WorkbenchCodiconSprite.ps1` from the adjacent vendored SVG files.

`discard-all.svg` is a local derivative of `discard.svg`, rotated 45 degrees clockwise to represent the Workbench's Undo All action. All other adjacent source SVG files preserve the selected upstream geometry.
