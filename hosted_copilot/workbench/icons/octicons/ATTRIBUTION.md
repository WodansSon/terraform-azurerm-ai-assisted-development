# GitHub Primer Octicons

The SVG files in this directory are selected icons from
[GitHub's Primer Octicons](https://github.com/primer/octicons)
at commit `6220ff87f3ddd923b05ffdac7e2d9cb714213205`.

Copyright GitHub Inc. Licensed under the [MIT License](LICENSE.txt).

`sprite.svg` combines the selected, unmodified icon geometry into SVG symbols for local Hosted Rule Workbench use. It is generated by `hosted_copilot/tools/New-WorkbenchOcticonSprite.ps1` from the adjacent vendored SVG files.
